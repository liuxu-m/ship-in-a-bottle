# 瓶中沧海 · A Sea in a Bottle

一艘三桅帆船，在封闭于横卧玻璃瓶内的海洋上航行。
体素微缩场景 · Three.js r160 · WebGL · 单文件

**在线体验：** <https://liuxu.github.io/ship-in-a-bottle/> （由 GitHub Pages 托管分发）

## 本地打开

直接双击 `index.html` 即可，无需构建、无需本地服务器。
（首次打开需联网从 CDN 拉取 three.js r160，已内置 5 个镜像源与 9 秒超时熔断。）

## 操作

| 操作 | 说明 |
| --- | --- |
| 拖动 / `←` `→` | 环视瓶身，静置 2.2 秒后自动恢复旋转 |
| 滚轮 / `+` `-` | 推近 / 拉远 |
| **按住 `Space`** | 掀起风暴（`F` 键可锁定，方便长时间观赏） |
| `1` `2` `3` | 延时摄影 ×1 / ×4 / ×12，驱动昼夜流转 |
| `0` 或 `P` | 暂停时间 |

## 实现要点

- **封闭性**：水体由 2135 根体素柱铺成，每根柱底严格贴合瓶腔内壁剖面，柱顶由顶点着色器驱动浪面位移；浪高在贴壁处按水深收敛，水面与玻璃严丝合缝。所有动态元素的生成范围按内壁半径硬约束，粒子有运行时越界回收兜底。
- **水面保持水平**：瓶内世界组与瓶体组平级，风暴时只摇晃瓶体。
- **渲染**：全场景约 7000 体素压缩进 8 个 InstancedMesh；玻璃折射走一张 0.7 倍分辨率离屏缓冲并带轻微色散。1920×1080 实测 114–120 FPS。
